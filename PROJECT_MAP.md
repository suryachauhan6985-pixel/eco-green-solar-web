## 1. SYSTEM OVERVIEW

- **Application Name**: Eco Green Solar Enterprise Web ERP (Dual Serial & Quantity Inventory, Solar BOM & Challan Engine, Accounting)
- **Architecture**: Single-Binary Deployment (Node.js/Express API + Vanilla JS Client SPA with Hash Routing)
- **Database Engine**: TiDB Cloud (AWS ap-southeast-1) / MySQL-compatible with Connection Pooling & In-Memory Redis-style Caching
- **Primary Operating Port**: `5000` (Dev & Render Production)

## 3. BACKEND API ENDPOINTS MAP

### Authentication & Tenant (`api/routes/auth.routes.js`, `api/middleware/auth.middleware.js`, `api/middleware/tenant.middleware.js`)
- `POST /api/auth/login` — Initiates login, sends 6-digit OTP to user email
- `POST /api/auth/verify-otp` — Verifies OTP, issues 10-year device JWT session
- `POST /api/auth/google-one-tap` — Google OAuth credential validation & auto-session
- `POST /api/auth/forgot-password` — Password reset trigger with email link/code
- `POST /api/auth/reset-password` — Password policy-checked reset
- `POST /api/auth/change-password` — Authenticated password change
- `GET /api/auth/app-settings` — Global ERP system parameters & company metadata
- `GET /api/auth/sessions` — Active device sessions list
- `POST /api/auth/revoke-session` — Revoke individual remote device session
- `POST /api/auth/revoke-other-sessions` — Revoke all other active sessions

### Masters Management (`api/routes/masters.routes.js`)
- `GET /api/masters/categories` — List all categories & item counts (In-memory cached)
- `POST /api/masters/categories` — Create category [Admin/SuperAdmin]
- `PUT /api/masters/categories/:oldName` — Rename & update serial/watt rules [Admin/SuperAdmin]
- `DELETE /api/masters/categories/:name` — Safe delete with item dependency check [Admin/SuperAdmin]
- `GET /api/masters/subtypes/:category` — Subtype list by category
- `POST/PUT/DELETE /api/masters/subtypes` — Subtype mutations [Admin/SuperAdmin]
- `GET/POST/PUT/DELETE /api/masters/units` — UOM management [Admin/SuperAdmin]
- `GET/POST/PUT/DELETE /api/masters/items` — Item catalog CRUD with Watt/Serial/Model overrides [Admin/SuperAdmin]
- `GET/POST/PUT/DELETE /api/masters/warehouses` — Warehouse/Godown location CRUD [Admin/SuperAdmin]
- `GET /api/masters/brands` — Distinct registered brands with item counts
- `GET/POST/PUT/DELETE /api/masters/users` — Staff user account & role management [Admin/SuperAdmin]

### Purchase & Inward Operations (`api/routes/purchase.routes.js`)
- `GET /api/purchase/brands/:category` — Brands registered under category
- `GET /api/purchase/wattages` — Wattages registered for Category + Brand
- `GET /api/purchase/models` — Models registered for Category + Brand
- `GET /api/purchase/check-serials` — Real-time duplicate & existence check
- `POST /api/purchase` — Atomic purchase inward with dual serial & quantity tracking
- `GET /api/purchase/find/:invoiceNo` — Find purchase invoice for editing
- `PUT /api/purchase/modify/:invoiceNo` — Modify purchase invoice with sold-stock guard
- `DELETE /api/purchase/delete/:invoiceNo` — Delete purchase invoice with rollback guard
- `GET /api/purchase/register` — Filtered inward transaction register

### Project Sales & Outward Dispatch (`api/routes/sales.routes.js`)
- `GET /api/sales/types` — Solar types/subtypes registered for product
- `GET /api/sales/check-line` — Pre-validate serials & available quantity before line addition
- `POST /api/sales/dispatch` — Atomic sales dispatch with FIFO quantity consumption & Challan assignment
- `GET /api/sales/find/:term` — Lookup sales order by Order No, Challan No, or Customer
- `PUT /api/sales/modify/:orderNo` — Modify dispatched sales order with stock restitution
- `DELETE /api/sales/delete/:orderNo` — Delete sales transaction with full stock rollback
- `GET /api/sales/register` — Outward register with line grouping

### Solar BOM & Partial Dispatch Engine (`api/routes/bom.routes.js`, `api/routes/bom_kits.routes.js`, `api/routes/challan.routes.js`)
- `GET /api/bom/kits` — Org-wide BOM kit templates
- `PUT/DELETE /api/bom/kits/:key` — Save / delete custom kit templates [Admin/SuperAdmin]
- `POST /api/bom/check-stock` — Pre-dispatch stock availability check
- `POST /api/bom/orders` — Create or update durable BOM order baseline
- `GET /api/bom/orders` — Pending BOM Register with remaining quantity calculations
- `GET /api/bom/orders/:id` — Continue dispatch item breakdown
- `GET /api/bom/orders/by-order-no/:orderNo` — Track BOM complete history & dispatch trips
- `POST /api/bom/dispatch` — Transactional BOM partial/full dispatch deduction
- `GET /api/challan/category-map` — BOM item to Challan row summary mappings
- `PUT /api/challan/category-map` — Save category compression map [Admin/SuperAdmin]
- `POST /api/challan` — Save Challan and trigger LibreOffice PDF generation + NAS Excel serial export
- `GET /api/challan/:id/pdf` — Stream generated Challan PDF

### Double-Entry Accounting & Financials (`api/routes/vouchers.routes.js`, `api/routes/ledgers.routes.js`)
- `GET /api/vouchers` — List accounting vouchers with search & date filters
- `POST /api/vouchers` — Create double-entry voucher [Admin/SuperAdmin]

- `GET /api/financial/statements` — Dynamic Trial Balance, Balance Sheet, Profit & Loss, Day Book

- `GET /api/ledgers/shortcodes` — Shortcode lookup for autocomplete
- `POST/PUT/DELETE /api/ledgers` — Party Master CRUD

### Inventory Reports, Backups, Attachments & Telemetry

- `POST /api/returns` — Sales returns and scrap/damage adjustment

8. `ledgers`, `accounting_vouchers` — Chart of accounts & double-entry financial journal
9. `attachments` — Base64 proof document storage
10. `scan_sheets`, `scan_sheet_entries` — Mobile barcode scanning sessions
